# Hotel Booking Management System

## Setup

1. Start Apache and MySQL in XAMPP.
2. Create/import the database by opening phpMyAdmin and importing `database/hotel_management.sql`.
3. If your MySQL root account has a password, update `includes/config.php`.
4. Open `http://localhost/project%20app/` in a browser (or place the folder inside XAMPP `htdocs`).

Default administrator account: **admin** / **admin123**.

## Included modules

Rooms, bookings, availability search, payments and invoices, staff, reports, dashboard, authentication, registration and password reset requests.
